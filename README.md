# EyeQ API and MQTT

Customer API reference for **RadiusVision EyeQ Spectrum Systems**.

**[Read the API and MQTT reference](https://radiusvision-dev.github.io/eyeq-api-mqtt/)**

- HTTPS authentication, permissions, functions and example requests
- MQTT authentication, topic names, commands and result handling
- Access Control, camera snapshots, video exports and system management

[Machine-readable catalog](catalog.json) · [Download the HTML reference](index.html)

Examples use placeholders and illustrative responses. Feature availability depends on the system version, configuration and granted permissions. Functions marked unavailable cannot be invoked.
